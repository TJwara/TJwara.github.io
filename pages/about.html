My Story

My Story

Front-end developer building responsive, accessible websites and web applications in HTML5, CSS3, JavaScript and React. I came to the web from mathematics. My BSc from the University of Johannesburg is in Mathematical Sciences, specialising in Applied Mathematics, and what I liked about it was never the arithmetic — it was taking something tangled and finding the structure underneath. Front-end development turned out to be the same job with a screen attached.

>

Since June 2023

I have been building websites and front-end applications for clients as a freelance developer, owning each project end to end: gathering requirements, designing the interface, writing the markup and component logic, integrating REST APIs, testing across devices, deploying, and handing over documentation the client can actually use. In March 2024 I completed the IBM Front-End Developer Professional Certificate, an eleven-course programme covering semantic HTML, CSS and JavaScript, UI and UX principles, Bootstrap, Git and GitHub, React, and a capstone application built against a live API.

✓

Skills:

• Front-end: HTML5, CSS3, JavaScript (ES6+), React, responsive and mobile-first design, web accessibility (WCAG)

• Back-end and data: Node.js, Python, RESTful APIs, JSON

• Cloud and tooling: AWS, Git, GitHub, automated builds, CI/CD fundamentals

• Analytics: advanced Excel, business intelligence, demand and supply chain analytics

I build with accessibility and mobile performance as requirements rather than polish, which matters in a market where most people reach your site on a phone and limited data.
